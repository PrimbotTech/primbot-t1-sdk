# 开发态脚本说明

本文档介绍了 `primebot_sdk` 目录及其子目录下各脚本的功能与使用方法。

---

## 1. 核心工具 (根目录)

### `streamline_sdk.py`
*   **功能**：SDK 接口精简提取工具。
*   **说明**：该脚本用于从完整的机器人源码树（`ros2/robot`）中，按照 `INTERFACE_MAP` 定义的列表，精确提取所需的 `.srv`, `.msg` 和 `.action` 文件到 SDK 的 `aimdk_msgs` 包中。它还会递归处理接口之间的消息嵌套依赖。
*   **适用场景**：当需要更新 SDK 包含的接口范围，或同步最新的接口定义时使用。

### `generate_md.py`
*   **功能**：接口列表文档生成工具。
*   **说明**：自动读取原始设计文档 `330二开接口列表.docx`，提取其中的“接口名称”列，并生成 Markdown 格式的 `330二开接口列表.md`。
*   **适用场景**：确保 SDK 文档中的接口名与原始设计文件保持同步。
